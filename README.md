# Rimforex

RimWorld 1.6 模组：给殖民地加一个**星际外汇交易终端**。
每个派系有自己的货币，用白银作保证金、加杠杆押涨跌。

**纯增量设计**：不修改原版任何交易逻辑，不使用 Harmony 补丁。

> 实现细节、数值推导与踩坑记录 → [`Docs/开发笔记.md`](Docs/开发笔记.md)

---

## 安装

**创意工坊**：订阅后在模组列表启用即可。

**手动**：把整个 `RimForex` 文件夹放进 `RimWorld\Mods\`。

**从 GitHub**（仓库里带着编译好的 DLL，克隆即可用）：

```powershell
cd <你的路径>\RimWorld\Mods
git clone https://github.com/D1fficu1t/Rimforex-FX.git RimForex
```

不需要 Harmony / HugsLib 作为前置。

---

## 快速上手

1. 研究 **电力**，在「生产」分类建造 **FX 交易终端**
   （钢铁 90 / 工业组件 4 / 白银 150，耗电 250W）
2. **通电**后选中终端 → 点 **Open FX terminal**
3. 在账户区**存入白银**作为保证金
4. 左侧选一种货币；右侧下单区填**保证金**、选**杠杆**，点 **做多** 或 **做空**
5. 平仓按钮在持仓行右侧 —— 需要跨过一次报价（约 3 秒）才解锁

## 关键数字

| 项 | 值 |
|---|---|
| 杠杆档位（滑块） | 1 / 2 / 3 / 5 / 8 / 10 / 15 / 20 / 30 / 50 / 75 / **100** 倍 |
| 点差（往返，按名义仓位） | **0.098% ~ 0.166%**，随货币波动率变化 |
| 手续费 | 单边 **0.02%**，每笔最低 **2 白银** |
| **预警线** | 净值跌到初始保证金的 **45%**（浮亏 55%）→ 暂停并弹窗 |
| **强平线** | 净值跌到 **30%**（浮亏 70%）→ 强制平仓，退还剩余净值 |
| 100 倍下的强平距离 | 反向约 **0.7%** |
| 报价间隔 | 3 现实秒（设置可调 1~10 秒） |
| 一根 K 线 | 6 次报价 ≈ 26 游戏分钟（可调 3~10 次） |
| 每日结算 | 1 游戏日 ≈ 16.7 现实分钟（1x 速度） |
| K 线历史 | 每级最多 100 根；分K / 时K / 日K 三级独立 |
| 心情联动 | 10 档，最多同时挂 3 条 |

## 玩法要点

### 保证金与杠杆

**你输入的是保证金，不是数量。**

```
名义仓位 = 保证金 × 杠杆
数量     = 名义仓位 ÷ 成交价   （向下取整）
实际占用 = 数量 × 成交价 ÷ 杠杆  （通常略低于输入值，差额不扣）
```

押同样的钱，杠杆越高仓位越大。**代价在风险**：

| 杠杆 | 100 倍 | 20 倍 | 1 倍 |
|---|---|---|---|
| 强平距离 | 0.7% | 3.5% | 70% |

### 做多与做空

- **做多**：价格涨就赚
- **做空**：**价格跌才赚**（先借来卖，跌了再买回来）

行情表与 K 线显示的是中间价；实际成交吃买/卖价，两者差一个**点差**。

### 点差是主要成本

点差按**名义仓位**在开仓和平仓各收一次。杠杆越高，点差占保证金的比例越大 ——
所以高杠杆短线天然吃亏。手续费远小于点差，只当作平台抽成。

### 锁定期

开仓后必须**跨过一次报价**才能平仓。同一报价步内平仓的订单会**作废并全额退款**。
锁定期内浮盈浮亏恒为 0（避免"一开仓就报警"）。

### 跳空与穿仓

行情会**跳空**（低概率的大幅单步移动）。罕见的极端跳空可能让亏损超过全部保证金 ——
账户余额被推成**负数**，此时：

- 无法开新仓
- 无法提款
- 必须存入白银把余额填回正数

### 每日结算

只在游戏内 **0 时**触发，只做"世界事件"通告（发结算信、记录当日盈亏），**不改变定价**。

交易本身是**实时**的：浮动盈亏和爆仓都随行情即时处理，不等结算。

### 心情

每一笔平仓都按该笔盈亏挂心情。十档，最多同时挂 3 条，满了挤掉最早的。
爆仓 −20，穿仓 −28（不叠加）。

**只影响自由殖民者** —— 囚犯、访客、任务寄宿者不共担殖民地的盈亏。

### 界面

- 终端窗口里可以直接改**游戏速度**（内嵌原版时间控制）
- 终端底部有「模组设置」按钮，不用退出就能改设置
- 关掉终端后，屏幕角落有**浮动盈亏小窗**（可拖动，可在设置里关掉）：
  点一下展开**每笔持仓的盈亏**，行尾可以直接**平仓**；右上角 `>>` 打开终端
  （平仓同样需要一台**通电**的终端 —— 断电时按钮会变灰）
- 终端可以**重新安装**：选中后点「重新安装」，小人会把它卸下来搬到新位置装好，
  **不消耗材料**；拆毁重建才需要重新出料
- K 线支持滚轮缩放、悬停查看单根开高低收
- 账户区右上角有「距下次结算 X 小时」
- 持仓区右上角 **交易历史**：汇总 + 逐笔明细，可一键**复制为纯文本报告**
  （制表符分隔，可直接粘进表格软件；报告里 `totalPnl` 是**毛盈亏**，净额要减 `totalFee`）

## 模组设置

- **显示开关**：报价节奏提示、K 线图例、结算倒计时、成本明细、时间诊断行
- **节奏滑块**：报价间隔（1~10 秒）、每根 K 线的报价数（3~10）
- **心情强度**：亏损 / 盈利 / 爆仓三个倍率（0 可关闭该类心情）
- **行情**：慢周期行情强度与长度
- **测试区**：叠心情、极端跳空、常规跳空、清理幽灵货币
